# تسليم مشروع منصة إحياء

تاريخ التوثيق: 2026-08-12

## الوضع الحالي

المشروع يعمل على النطاق الحي `https://ihyaa.alrahmakuran.site/` ويعتمد على PostgreSQL حقيقية. جرى استيراد بيانات المؤسسة السابقة وتحويلها إلى حلقات وطلاب وسجلات حضور ومتابعة قرآن، ثم ربط لوحة الإدارة وواجهة المعلم بنفس مصدر البيانات. هذه النسخة جاهزة للاستخدام التشغيلي الحالي للحضور والمتابعة القرآنية، مع بنية قابلة للتوسع لاحقًا.

لا تُحفظ نسخة من بيانات الإنتاج أو أسرار الخادم داخل المستودع. المستودع يحتوي الكود، المخطط، migrations، ومُستورد البيانات فقط.

## مصدر البيانات

- **الإنتاج:** PostgreSQL، وهي مصدر الحقيقة الوحيد للطلاب والحلقات والحضور والتسميع.
- **البيانات الأولية:** استوردت تاريخيًا من ملف متابعة Google Sheets عبر ملف JSON خارجي و`server/seed.mjs`؛ الملف الأصلي غير موجود في Git.
- **Migrations:** تُطبّق عبر `npm run db:migrate`. لا تعدّل migration منفذة في الإنتاج؛ أضف ملفًا جديدًا مرقّمًا.

## المستخدمون والصلاحيات

- `admin`: يملك الوصول الكامل للحلقات والمعلمين والطلاب والسجلات والتقارير واعتماد الجلسات.
- `teacher`: يرى الدوائر المسندة إليه فقط، وطلابها النشطين فقط، ولا يستطيع تسجيل أو تعديل سجلات خارج حلقة إسناده.
- كلمات المرور تحفظ كـ hash في جدول `users`، والجلسات في `user_sessions`. لا توثق أي كلمات مرور هنا.

## أولويات المرحلة التالية

1. تغيير كلمات الدخول التجريبية وتفعيل سياسة كلمات مرور مناسبة قبل تسليم موسع.
2. نسخ احتياطية دورية لقاعدة البيانات وتوثيق خطة الاستعادة.
3. إشعارات الغياب والتواصل مع أولياء الأمور مع موافقات وخصوصية واضحة.
4. خطة حفظ ومراجعة مفصلة، وأهداف أسبوعية وتقارير تربوية.
5. تصدير تقارير PDF/Excel وصلاحيات إدارية أدق وسجل تدقيق أوسع.

## قيود وملاحظات معروفة

- لا توجد حالياً واجهة لاستعادة حساب أو إرسال بريد؛ إدارة كلمة المرور تتم من لوحة الإدارة.
- لا يتضمن المستودع إعداد reverse proxy أو PM2 أو بيانات الخادم؛ ذلك مقصود لمنع تسريب الأسرار.
- اختبار API التشغيلي ينشئ بيانات مؤقتة ثم يحذفها، ولا ينبغي تشغيله على الإنتاج إلا بحساب إدارة مخصص للاختبار وإذن واضح.
- يجب فحص قدرة الجوال يدويًا بعد أي تعديل كبير في الجداول أو النوافذ المنبثقة.

## اختبار يدوي سريع

1. افتح `/login` وسجّل الدخول كإدارة؛ تحقق من ظهور الأرقام الفعلية وتبويبات الإدارة.
2. من الطلاب، افتح طالبًا وانقل الحلقة: يجب أن يظهر المصدر والوجهة قبل التأكيد، ثم يظهر السجل في ملف الطالب.
3. من المعلمين، أضف حساب اختبار أو عدّل حسابًا تجريبيًا وتحقق أن الإسناد ظاهر في قائمة المعلمين.
4. سجّل الدخول كمعلم مسند إليه حلقة؛ تحقق أنه لا يرى إلا طلاب حلقته.
5. في السبت سجّل حضورًا، وفي الأحد سجّل حاضرًا ثم تسميعًا لطالب؛ احفظ وأعد فتح اليوم نفسه لتتحقق من عدم تكرار السجل.
6. عُد للإدارة وافتح الحضور ومتابعة القرآن والتقارير؛ تحقق من ظهور السجل مباشرة.
7. شغّل `npm run build` و`node --test tests/schedule.test.mjs tests/sites-worker.test.mjs` قبل أي تسليم.
