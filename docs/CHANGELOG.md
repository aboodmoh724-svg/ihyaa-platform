# سجل التغييرات

يتبع المشروع صياغة مبسطة من Keep a Changelog. التواريخ تصف حالة الكود الموثقة، لا تاريخ جميع سجلات المؤسسة.

## 2026-08-12 — النسخة التشغيلية الأولى

### أضيف

- واجهة عامة لمؤسسة إحياء، وتسجيل دخول عربي RTL.
- واجهة إدارة للحلقات والمعلمين والطلاب والحضور ومتابعة القرآن والتقارير.
- واجهة معلم مقيدة بحلقاته وطلابه، مع حفظ الحضور والتسميع وتعديل سجل اليوم نفسه.
- مخطط PostgreSQL للحلقات والطلاب والجلسات والحضور والتسميع والجلسات الأمنية.
- سجل تاريخي لانتقالات الطلاب بين الحلقات يوضح المصدر والوجهة والمنفذ والتاريخ.
- migrations متسلسلة وseed importer للبيانات الأولية الخارجية.
- اختبارات للجدولة وملفات الاستضافة واختبار API تشغيلي.

### غُيّر

- رُبطت لوحة الإدارة وواجهة المعلم بمصدر PostgreSQL الحقيقي بدل بيانات تجريبية منفصلة.
- أُعيد توضيح نقل الطالب في الواجهة إلى «من → إلى» مع تأكيد قبل التنفيذ.
- حُسّن الوصول إلى تبويبات الإدارة على الجوال.

### ملاحظات

- لا تُدرج أي بيانات دخول أو نسخة قاعدة بيانات في المستودع.
- ميزات أولياء الأمور والإشعارات والمنهج التفصيلي مؤجلة لإصدار لاحق.
